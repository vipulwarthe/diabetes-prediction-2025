- after installtion of all the tools and services access jenkins and do all the setup and Buid the pipeline.

- after succefully completed the pipeline we need to create ECS service/Task defination manully so it will create the task automatically.

- go to the ECS cluster click on task - access the application using public IP of Task with 8501 port. fill required details and you will get the result.

so finally we have created automated CICD pipeline for diabeted prediction app deployment.

In that Jenkins pipeline we have checkout code in SCM which is GITHUB, using that github repo in that we have created dockerfile for build the docker image. 
After that we have scan the image, then login to the AWS and after that we have login to the ECR repo and push the docker image into it and deploy the image to the ECS cluster.
